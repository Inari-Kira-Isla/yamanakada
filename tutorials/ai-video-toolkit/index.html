AI 剪片工具清單＋一鍵安裝

建築AI男 EP1 實際用過嘅 7 個工具，每個講用嚟做乜、點裝、官方網址喺邊。撳一個掣複製提示詞，貼畀你嘅 AI，佢逐個幫你檢查同安裝。

作者 Joe｜從事水產貿易嘅建築AI男 · 指令核實日期 2026-11-16 · macOS · 約 6 分鐘讀完

一鍵複製

貼畀 Claude Code（或 Codex）：逐個檢查同安裝

提示詞只會處理下面 7 個工具。全域安裝、登入、會用額度嘅動作，佢會先問你。

你係我嘅 AI 助手。請幫我喺 macOS 逐個檢查同安裝以下 7 個剪片工具。逐步做，每步講結果：
1. 先檢查有冇 brew、node（要 ≥22）、python3、pip3；冇嘅話停低告訴我，由我決定點裝，你唔好自己裝 Homebrew、Node 或 Python。
2. 逐個用指令檢查有冇裝：claude --version、codex --version、npx --no-install hyperframes --version、ffmpeg -version、pip3 show playwright、whisper --help、pip3 show opencv-python。已經裝咗嘅跳過。
3. 未裝嘅，用以下官方指令：
   - Claude Code：npm install -g @anthropic-ai/claude-code
   - Codex CLI：npm install -g @openai/codex
   - HyperFrames：npm install -g hyperframes（要 Node ≥22 同 ffmpeg）
   - ffmpeg：brew install ffmpeg
   - Playwright：pip3 install playwright ，再 python3 -m playwright install chromium
   - Whisper：brew install openai-whisper
   - OpenCV：pip3 install opencv-python ，YuNet 模型由 https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet 下載 face_detection_yunet_2023mar.onnx
4. 每一個全域安裝（npm -g、brew、pip）之前，先逐個問我，等我講「做」先做。
5. 登入一律由我自己做：Claude Code 要 Claude 訂閱或帳號，Codex 用 ChatGPT 帳號登入。你唔好代我登入，亦唔好幫我買或者升級任何訂閱。
6. 淨係處理呢 7 個，唔好裝其他工具；唔好改我其他設定，唔好刪檔。
7. 最後用一個表格列出每個工具：已裝／新裝／跳過、版本號。

Claude Code 要 Claude 訂閱或帳號先用到，Codex 用 ChatGPT 帳號登入（Free 都得）。未裝 Claude Code 或 Codex 嘅話，先自己裝其中一個，再貼提示詞。

EP1 實際用過嘅 7 個工具

下面每個都係 EP1 製作過程用過。指令喺 2026-11-16 逐條對過官方來源，同本機版本核實，結果寫喺每張卡。

Claude Code 需要訂閱／帳號

用嚟做乜：寫劇本、拆分鏡、寫剪接腳本，成個流程由佢統籌。

npm install -g @anthropic-ai/claude-code

要 Claude 訂閱或帳號先用到，並唔係完全免費。官方網址：code.claude.com/docs/en/setup。本機版本 2.1.325。

Codex CLI 需要 ChatGPT 帳號

用嚟做乜：獨立覆檢，同 Claude 分開睇一次有冇錯。

npm install -g @openai/codex

用 ChatGPT 帳號登入，Free 都得。官方網址：github.com/openai/codex。本機版本 codex-cli 0.159.2。同 Claude 點樣互相用，睇雙AI 教學。

HyperFrames 免費

用嚟做乜：用 HTML 做動畫字卡，輸出成影片。

npm install -g hyperframes

唔想全域安裝，可以直接 npx hyperframes init my-video。要 Node.js 22 或以上，同埋 ffmpeg。官方網址：hyperframes.heygen.com。npm 套件名係 hyperframes，本機版本 0.9.19。

ffmpeg 免費

用嚟做乜：切片、拼接、轉格式、混音，EP1 嘅剪接同混音都靠佢。

brew install ffmpeg

官方網址：ffmpeg.org。本機版本 8.1.1。

Python Playwright 免費

用嚟做乜：自動開網頁並錄屏，EP1 片尾嘅網頁介紹段就係咁錄。

pip3 install playwright
python3 -m playwright install chromium

官方網址：playwright.dev/python。本機版本 1.58.0。

Whisper 免費

用嚟做乜：將配音轉成文字，對字幕同讀音。粵語夾英文會有錯，要人耳再聽。

brew install openai-whisper

官方網址：github.com/openai/whisper。本機版本 20250625_5。

OpenCV YuNet 人臉偵測 免費

用嚟做乜：逐格量字卡、字幕有冇遮住人臉。

pip3 install opencv-python

YuNet 模型 face_detection_yunet_2023mar.onnx 喺 OpenCV 官方 model zoo 下載：github.com/opencv/opencv_zoo。呢條 pip 指令確認套件存在（最新 5.0.0.93），本機未重新安裝實測。

點樣組合：EP1 嘅流程

  1. 劇本：Claude Code 寫，Codex 獨立睇一次。
  2. 分鏡：Claude Code 拆成逐鏡清單。
  3. 生成：用你揀嘅畫面生成服務出片，呢頁唔列。
  4. 字卡：HyperFrames 做動畫字卡，Playwright 錄網頁段。
  5. 剪接：ffmpeg 按分鏡切同拼。
  6. 混音：ffmpeg 混配音同背景音。
  7. 覆檢：Whisper 轉文字對稿，OpenCV YuNet 量字卡有冇遮臉，Codex 再審一次。

Claude 同 Codex 點樣互相叫對方做嘢，睇雙AI 教學：Claude 用 Codex，Codex 用 Claude。

其他免費工具（我哋未喺 EP1 用，供參考）

未經 EP1 實測

呢節嘅工具冇喺 EP1 用過，淨係對過官方網址同 Homebrew 紀錄。一鍵提示詞唔會裝呢節嘅工具。

DaVinci Resolve（免費版）

用嚟做乜：完整剪輯、調色、混音軟件。官方有免費版，功能有限制，詳情睇官網。

冇 Homebrew cask，要喺官網下載：blackmagicdesign.com

OBS Studio

用嚟做乜：錄屏、直播。

brew install --cask obs

官方網址：obsproject.com（開源）

Audacity

用嚟做乜：音訊剪輯、去噪、錄音。

brew install --cask audacity

官方網址：audacityteam.org

HandBrake

用嚟做乜：轉檔同壓縮影片。

brew install --cask handbrake-app

官方網址：handbrake.fr（開源）

Shotcut

用嚟做乜：開源影片剪輯軟件，有畫面介面。

brew install --cask shotcut

官方網址：shotcut.org

ImageMagick

用嚟做乜：用指令批量改圖片尺寸、格式。

brew install imagemagick

官方網址：imagemagick.org

SoX

用嚟做乜：用指令處理音訊，轉格式、改音量、拼接。

brew install sox

官方網址：sox.sourceforge.net

常見問題

清單入面嘅工具全部免費嗎？

ffmpeg、HyperFrames、Playwright、Whisper、OpenCV 呢 5 個係免費。Claude Code 要 Claude 訂閱或帳號，Codex 用 ChatGPT 帳號登入（Free 都得）。呢頁淨係列剪片同後期工具，唔包生成影片畫面嘅服務。

冇編程經驗都裝得到嗎？

得。將頁頂嘅提示詞貼入 Claude Code 或 Codex，佢會逐個檢查同安裝；遇到全域安裝、登入、會用到額度嘅位會先問你，你答「做」或者「唔做」就得。

一定要全部 7 個都裝嗎？

唔使。ffmpeg 係剪接混音嘅底，裝呢個已經做到基本剪片。其餘按需要：要動畫字卡先裝 HyperFrames，要轉字幕先裝 Whisper，要檢查字卡有冇遮臉先裝 OpenCV。
