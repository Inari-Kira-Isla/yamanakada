雙AI 教學：Claude 用 Codex，Codex 用 Claude

兩個方向都行得通：喺 Claude Code 入面叫 Codex 審 code，或者喺 Codex 入面叫 Claude Code 做工具。下面兩段提示詞，一鍵複製，貼畀你嘅 AI 就會幫你裝。

作者 Joe｜從事水產貿易嘅建築AI男 · 實測日期 2026-11-15 · 約 8 分鐘讀完

一鍵複製：貼畀你嘅 AI

揀你用緊嘅 AI，撳大掣複製，貼入去，佢會逐步幫你做。全域安裝、登入、耗額度嘅動作，提示詞已寫明要先問你。

方向 A

貼畀 Claude Code：等 Claude 識用 Codex

裝 OpenAI 官方 Codex 外掛，之後喺 Claude 入面打 /codex:review 就叫到 Codex 審 code。

你係我嘅 Claude Code 助手。請幫我裝好 OpenAI 官方 Codex 外掛（https://github.com/openai/codex-plugin-cc）。逐步做，每步講結果：
1. 檢查：node --version（要 ≥18.18）、codex --version、codex login status；冇 codex CLI 或未登入就停低，叫我自己喺終端機做（npm 全域安裝同登入由我親手做，你唔好代做）。
2. 執行：claude plugin marketplace add openai/codex-plugin-cc ，然後 claude plugin install codex@openai-codex ，再 claude plugin list 確認見到 codex@openai-codex。
3. 叫我喺聊天框打 /reload-plugins，再打 /codex:setup（會顯示 Codex 係咪已就緒、已登入；未登入就叫我打 !codex login）。
4. 教我三個指令：/codex:review（審查未 commit 改動，要喺有改動嘅 git 資料夾，可加 --wait）、/codex:adversarial-review（挑戰式審查）、/codex:rescue（交畀 Codex 接手難題）。
5. 唔好開 review gate（/codex:setup --enable-review-gate 會每次停止都叫 Codex 審查，好食額度）。
6. 遇到全域安裝、登入、或者會耗用我額度嘅動作，一律先問我，等我講「做」先做。
全程唔好改我其他設定，唔好刪檔。

方向 B

貼畀 Codex：等 Codex 識用 Claude

將 Claude Code 加成 Codex 嘅 MCP 工具，之後 Codex 可以叫 Claude 做嘢。

安全警告：default_tools_approval_mode="approve" 等於畀 Codex 用 Claude 嘅 Bash 等工具。只喺你信任嘅資料夾用；建議用單次 -c 覆寫，唔好寫死入設定檔。
你係我嘅 Codex 助手。請幫我設定 Codex 用 Claude Code 做 MCP 工具：
1. 檢查 claude --version 同 codex --version；冇 claude 就停低告訴我。
2. 執行：codex mcp add claude -- claude mcp serve ，再 codex mcp list 同 codex mcp get claude 確認 claude 係 enabled。
3. 教我試用：喺一個我信任嘅資料夾跑
codex exec --skip-git-repo-check -c 'mcp_servers.claude.default_tools_approval_mode="approve"' "Use the claude MCP server's tools to list the files in the current directory, then reply with just the file names." </dev/null
（非互動 exec 預設會擋 MCP 工具：「requires approval, but approval policy is never」，所以要呢個 -c 旗標。）
4. 提醒我：呢個旗標等於畀 Codex 用 Claude 嘅 Bash 等工具，只喺信任嘅資料夾用；唔好開 --dangerously-bypass-approvals-and-sandbox。
5. 唔好將 default_tools_approval_mode 寫死入 ~/.codex/config.toml，只用單次 -c 覆寫。
6. 遇到全域安裝、登入、或者會耗用我額度嘅動作，一律先問我，等我講「做」先做；唔好自己開 review gate。
7. 還原：codex mcp remove claude

方向 A

Claude 用 Codex：一個做，一個審

OpenAI 官方外掛 codex-plugin-cc，喺 Claude Code 入面一行指令叫 Codex 開工。以下 5 步，每步都係你手動做嘅版本（提示詞係叫 Claude 代你做）。

方向 A：開始前要有乜

  • Claude Code：呢個外掛係畀 Claude Code 用家做嘅，要先裝好。
  • Node.js 18.18 或以上
  • ChatGPT 帳號（Free 都得）或者 OpenAI API key
  • 你嘅專案要係 git repo：Codex 審嘅係 repo 入面嘅改動，下面有講。
  • 用量計入你嘅 Codex 額度：Codex 做幾多嘢，就食幾多你嘅 Codex 用量限額。
1

安裝外掛喺 Claude Code 入面打，3 行

逐行貼入 Claude Code 嘅對話框，每行撳一次 Enter：

/plugin marketplace add openai/codex-plugin-cc
/plugin install codex@openai-codex
/reload-plugins

第一行加入 OpenAI 官方外掛市集，第二行裝 Codex 外掛，第三行重新載入外掛。裝好之後，你會見到下面幾條 /codex: 開頭嘅指令，而 /agents 入面亦會多咗個 codex:codex-rescue subagent。

2

檢查接駁/codex:setup

/codex:setup

佢會檢查你部機有冇裝 Codex、有冇登入。如果 Codex 未裝，而你有 npm，佢可以提出幫你裝。想自己裝，就用呢行：

npm install -g @openai/codex

Codex 裝咗但未登入，就喺 Claude Code 入面打（前面嗰個感嘆號要打）：

!codex login

要留意：/codex:setup 只係檢查同引導登入。真正把外掛裝入 Claude Code 嘅，係第 1 步嗰 3 行。

3

叫 Codex 審一次/codex:review

Claude 寫完一輪，就打 /codex:review。Codex 會做一次標準 code review，質素同你直接喺 Codex 入面打 /review 一樣。你可以審兩樣嘢：

  • 你而家未 commit 嘅改動
  • 成條分支同 main 之類 base 分支嘅差異（加 --base）
/codex:review
/codex:review --base main
/codex:review --background

改動多個檔案嘅話，審查會需要啲時間，官方建議喺背景跑。加 --background 之後，用 /codex:status 睇進度，完成後用 /codex:result 睇結果：

/codex:review --background
/codex:status
/codex:result

呢個指令唯讀，唔會改你任何檔案。佢亦唔可以帶自訂重點，想叫 Codex 專登質疑某個位，用第 4 步。睇完 Codex 指出嘅問題，叫 Claude 去改就得。

4

叫 Codex 專登唱反調/codex:adversarial-review

普通 review 睇嘅係「呢段 code 啱唔啱」。/codex:adversarial-review 再行前一步：質疑你揀咗嘅做法，問你有冇更安全、更簡單嘅路。佢揀審查範圍嘅方式同 /codex:review 一樣，但可以喺後面加重點文字：

/codex:adversarial-review
/codex:adversarial-review --base main challenge whether this was the right caching and retry design
/codex:adversarial-review --background look for race conditions and question the chosen approach

幾時用：出貨前、或者大改動、架構決定之後。官方列出嘅重點位包括 auth、資料遺失、rollback、race condition、可靠性。同樣係唯讀，只提問題，唔會幫你修 code。

5

Review gateClaude 一做完，Codex 自動審（慎用）

/codex:setup --enable-review-gate
/codex:setup --disable-review-gate

第一行開，第二行閂。開咗之後，Claude 每次答完，外掛會用 Stop hook 叫 Codex 針對 Claude 嘅回覆做一次審查。如果審出問題，Claude 就停唔到，要先處理完。即係「唔過唔收工」。

額度警告

Review gate 可能形成 Claude 同 Codex 長時間來回嘅循環，好快食晒你嘅用量限額。官方嘅講法係：只喺你打算全程睇住個 session 嗰陣先開。

實際做法：平時用第 3、4 步手動審就夠。大工程、重要改動先開 review gate，做完即刻 --disable-review-gate 閂返。

方向 A 進階：交嘢畀 Codex，或者成個對話搬過去

/codex:rescue：將任務交畀 Codex 做

前面 Codex 一直係審嗰個。用 /codex:rescue 就可以反過來，由 Claude 派工、Codex 落手：查 bug、試修、接續上一個 Codex 任務，或者用較細嘅模型快手過一次。

/codex:rescue investigate why the tests started failing
/codex:rescue fix the failing test with the smallest safe patch
/codex:rescue --resume apply the top fix from the last run
/codex:rescue --background investigate the regression

支援 --background、--wait、--resume、--fresh。唔指定模型同 effort，Codex 用自己嘅預設。

/codex:transfer：成個 Claude Code 對話搬去 Codex

喺 Claude Code 傾咗一大輪 debug 或者實作，想原封不動喺 Codex 繼續，就打：

/codex:transfer

外掛會由你而家嘅 Claude Code 對話開一個持續嘅 Codex thread，並印出一行 codex resume <session-id> 畀你，照呢行去 Codex 接住做。如果你 Codex 版本太舊、冇 session import 功能，要先升級。

其他管理背景任務嘅指令：/codex:status（睇進度）、/codex:result（睇結果）、/codex:cancel（取消）。

方向 B

Codex 用 Claude：將 Claude Code 當 MCP 工具

Claude Code 本身可以做 MCP server，其他應用接駁到佢就用到 Claude 嘅工具。Codex 有 codex mcp add，所以兩邊駁埋就得。以下指令 2026-11-15 實測跑通。

1. 加入 claude MCP server

codex mcp add claude -- claude mcp serve

成功會見到 Added global MCP server 'claude'。-- 後面嗰段係啟動 Claude Code MCP server 嘅指令。

2. 確認有加到

codex mcp list
codex mcp get claude

實測見到 claude 係 enabled、stdio、command 係 claude、args 係 mcp serve。

3. 用法示例（單次覆寫批准）

喺一個你信任嘅資料夾跑：

codex exec --skip-git-repo-check -c 'mcp_servers.claude.default_tools_approval_mode="approve"' "Use the claude MCP server's tools to list the files in the current directory, then reply with just the file names." </dev/null

點解要加 -c：非互動嘅 codex exec 預設唔准 MCP 工具，實測唔加會見到「MCP tool call requires approval, but approval policy is never」。加咗之後，Codex 用 Claude 嘅 Bash 列出資料夾檔案，成功。

安全警告

default_tools_approval_mode="approve" 等於畀 Codex 用 Claude 嘅 Bash 等工具，即係畀咗執行權。只喺你信任嘅資料夾用。

用上面嗰種單次 -c 覆寫，唔好寫死入 ~/.codex/config.toml；亦唔好同時開 --dangerously-bypass-approvals-and-sandbox。唔想用嘅時候，codex mcp remove claude 就移走。

方向 B 官方來源：Claude Code 文件嘅 Use Claude Code as an MCP server（原文：「You can use Claude Code itself as an MCP server that other applications can connect to: claude mcp serve」）；Codex 嘅 MCP 文件（codex mcp add 同 default_tools_approval_mode）。

建築AI男嘅講法：畫圖同審圖

建築師畫完圖，唔會自己審自己，會交結構工程師過一次。Claude Code 係畫圖嗰個，Codex 係審圖嗰個。兩個唔使揀邊個，一個畫、一個審，圖先過得關。

第 3 步嘅 /codex:review 好似結構工程師核對尺寸、荷載。第 4 步嘅 /codex:adversarial-review 就係工程師問一句：「點解唔用另一種結構？」

講清楚，呢個只係比喻。Codex 實際審嘅唔係設計圖，係你 git repo 入面嘅 code：未 commit 嘅改動，或者分支對比 base 嘅差異。純做設計、唔寫 code 嘅工作流，呢個外掛用唔到。

常見問題

要另外開一個 Codex 帳號嗎？

如果你部機已經登入咗 Codex，外掛即用。如果你淨係用 Claude Code、未用過 Codex，就要用 ChatGPT 帳號（Free 都得）或者 API key 登入 Codex。打 /codex:setup 檢查，未登入就打 !codex login。

外掛會另外開一個 Codex 運行環境嗎？

唔會。外掛通過你本機嘅 Codex CLI 同 Codex app server 做嘢：同一個安裝、同一個登入狀態、同一個 repo checkout 同本機環境。

我已經有 Codex 設定或者 API key，外掛用得到嗎？

用得到。外掛用你本機 Codex CLI，所以你現有嘅登入方式同 config 照樣有效，包括 ~/.codex/config.toml，以及專案裡面嘅 .codex/config.toml（專案層設定要專案已被 Codex 信任先會載入）。

/codex:review 同 /codex:adversarial-review 有咩分別？

/codex:review 係一般唯讀審查，唔可以帶自訂重點。/codex:adversarial-review 可以喺後面加重點文字，專登質疑你揀嘅實作同設計取捨。兩個都係唯讀，都唔會改你嘅檔案。

Codex 用 Claude 安唔安全？

要睇你點設。Codex 用 Claude 係將 Claude Code 當 MCP server。非互動 codex exec 預設會擋 MCP 工具，要加 default_tools_approval_mode="approve" 先行得，而呢個等於畀 Codex 用 Claude 嘅 Bash 等工具。

做法：只喺信任嘅資料夾用、用單次 -c 覆寫、唔寫死入 config、唔開 --dangerously-bypass-approvals-and-sandbox。

兩個方向要唔要同時裝？

唔使。方向 A 係喺 Claude Code 裝外掛，方向 B 係喺 Codex 加 claude MCP server，兩邊獨立。你想邊個方向就裝邊個；兩邊都想要，就分開做兩次。

官方來源（兩個方向）

  • OpenAI 官方 repo 同 README：github.com/openai/codex-plugin-cc（方向 A 每條指令同說明都對照呢份 README）
  • Claude Code 做 MCP server：code.claude.com/docs/en/mcp（方向 B）
  • Codex MCP 文件：developers.openai.com/codex/mcp（方向 B；codex mcp add、default_tools_approval_mode）
  • Codex 用量同定價：developers.openai.com/codex/pricing
